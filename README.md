# 拾法 · JURIS GLEANINGS

> 法考备考单文件应用 · 2027 年法律职业资格考试

一个纯前端、零依赖、无需安装的法律职业资格考试（法考）备考应用。打开即用，数据保存在本地浏览器中。

## ✨ 功能

- **📈 备考总览**：考试倒计时、累计作答统计、正确率、错题追踪、今日一练（10 题混合卷）
- **📚 八科刷题**：刑法 / 民法 / 刑诉 / 民诉 / 行政 / 商经知 / 三国法 / 理论法，2300+ 道客观题（含 2018–2025 八年真题完整卷、仿真卷、专项题库），逐题解析引用具体法条
- **📝 全真模考**：100 题完整卷、180 分钟倒计时、自动交卷、300 分制折算（180 及格），仿真考场体验
- **🧮 智能组卷**：按科目 / 题型 / 难度自定义组卷
- **⚖️ 主观题考场**：12 道主观题专项训练
- **📖 法条速查**：12 部全本法典（3232 条）+ 127 条精选法条，词典式点击展开，含要旨 / 解析 / 易错提示
- **🗂 知识点精讲**：73 讲考点讲义，含 51 个典型案例
- **❌ 错题集**：自动收录错题，支持重做与掌握度标记

## 🚀 使用

**在线使用**：开启 GitHub Pages 后访问 `https://shaochidianhehe-glitch.github.io/shifa-fakao/`

**本地使用**：下载仓库 zip 解压，双击 `index.html` 即可（需保留 `tiku/` 文件夹与 index.html 同级）

## 💾 数据说明

- 所有学习进度保存在浏览器 `localStorage` 中，请勿清除站点数据
- 换设备 / 换浏览器进度不互通
- 真题依公开回忆版整理，仅供个人备考参考；模拟题为依考情原创编写

## 🛠 技术栈

纯 HTML + CSS + JavaScript（原生，无任何依赖 / 构建工具），题库以 JS 数据文件形式按需加载。
